# Sharp Favard decay with uniform marginals

Sergiu Alexandru Bîsceanu

We construct a compact planar set of Hausdorff length $1$ whose length measure has uniform coordinate marginals and whose $\delta$-neighborhoods have Favard length of order $\frac{1}{\log\frac{1}{\delta}}$. Hall's matching theorem gives the sharp bound $\alpha_n\asymp\frac{1}{\log n}$ for unions of permutation strips (KC2).
